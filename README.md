# 🏏 Exploratory Data Analysis on IPL Dataset

This repository contains a Jupyter Notebook titled `EDA on IPL.ipynb` that performs exploratory data analysis (EDA) on data from the **Indian Premier League (IPL)**. The notebook explores player performance, match outcomes, and team statistics to uncover trends and patterns in the tournament's history.

---

## 📂 Contents

* `EDA on IPL.ipynb`: Main notebook containing all the analysis and visualizations.


## 🧠 Key Features

* **Data Cleaning & Preprocessing**
  Preparing raw IPL data for analysis by handling nulls, restructuring columns, and filtering relevant information.

* **Exploratory Data Analysis**
  Analyzing trends across seasons, players, teams, and venues.

* **Visualizations**
  Insightful plots and charts (e.g., top run-scorers, most wickets, winning trends, toss decisions, etc.) using libraries like `matplotlib`, `seaborn`.

* **Insights & Observations**
  Highlights trends such as:

  * Which teams have been most successful?
  * What factors influence match results?
  * Highest run-getters or wicket-takers over the seasons.


## 📊 Dataset

The notebook uses IPL dataset(s) which typically include:

* Match results
* Player statistics
* Team profiles
* Venue information
  
## 🛠️ Tools & Technologies

* **Python**
* **Jupyter Notebook**
* **Pandas** and **Numpy** for data manipulation
* **Matplotlib**, **Seaborn** for visualizations
